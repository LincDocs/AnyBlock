如何修改正则

插件将正则相关的内容放在了 ABReg.ts 文件中，如果对匹配规则不满意，只需要修改那个文件并重新编译就行了？

如何编译？相关文档在源项目的 /src/README.md 中

Note

在3.1.9版本及之后，部分正则（如内联切割符），可以在插件文件夹中的配置文件 (data.json) 中进行修改
